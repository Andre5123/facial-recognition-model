# Dataset: CASIA-WebFace

## Source

Downloaded via the Kaggle mirror:
https://www.kaggle.com/datasets/yakhyokhuja/webface-112x112

Local path (not committed to git): `webface_112x112/`

## License / usage terms

The original CASIA-WebFace dataset was released by the Institute of
Automation, Chinese Academy of Sciences (CBSR) under a **CASIA-WebFace
Database Release Agreement**. Per that agreement (and corroborating
secondary sources, since the primary CBSR server was unreachable when
checked):

- Use is restricted to **non-commercial research and educational purposes
  only**.
- Formal access to the original dataset requires a signed release agreement
  submitted to CBSR/CASIA.
- CASIA reserves the right to revoke access at any time.

**Caveat:** the Kaggle mirror used here (`yakhyokhuja/webface-112x112`)
redistributes pre-aligned copies of the images without going through that
formal per-researcher agreement process. Kaggle's own listing did not
expose a distinct license statement when checked (2026-08-22). This project
treats the data under the original CASIA-WebFace terms (non-commercial
research/educational use only) to be safe, since that is the only license
that is actually documented for this data. Do not use models trained on it
for any commercial purpose, and do not redistribute the images.

This is why the dataset is excluded from the git repository (see
`.gitignore`) and why no image files are committed anywhere in this
project.

## Actual format (verified 2026-08-22 via `scripts/inspect_dataset.py`)

- Layout: one directory per identity (`id_0/`, `id_1/`, ... `id_10617/`),
  matching the "one folder per identity" assumption in
  `scripts/make_identity_split.py`.
- Identities: 10,572
- Total images: 490,623
- Images per identity: min 2, max 802, mean ~46.4
- File format: all `.jpg`
- Image size/mode: uniformly 112x112 RGB, already aligned and cropped --
  **no face detection/alignment preprocessing is needed**; only
  normalization and augmentation remain for the data pipeline.
- No LICENSE or README file is bundled inside the dataset directory itself.

## Identity split

Generated by `scripts/make_identity_split.py --data-root webface_112x112
--output-dir data/splits --seed 42` (manifests are gitignored under
`data/splits/`, regenerate locally with this exact command for
reproducibility):

| split | identities | images | purpose |
|---|---|---|---|
| train | 10,043 | 419,680 | training set |
| val_seen | 10,043 (subset of train identities) | 47,017 | seen identity / unseen image eval |
| test_unseen | 529 | 23,926 | unseen identity eval (never in training) |

- `unseen_identity_fraction=0.05`, `held_out_image_fraction=0.1`, `seed=42`
  (see `configs/baseline.yaml`).
- 419,680 + 47,017 + 23,926 = 490,623, i.e. every image is accounted for
  exactly once across the three splits.
