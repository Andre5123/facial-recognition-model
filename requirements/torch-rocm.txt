# GPU training environment: install inside WSL2 (Ubuntu), not native Windows.
#
# The Radeon 880M (Strix Point / gfx1103) is not supported by ROCm on native
# Windows. It IS supported via WSL2 + ROCDXG, which requires:
#   - AMD Software: Adrenalin Edition 26.2.2 or later, installed on the
#     Windows host (not inside WSL)
#   - Ubuntu 22.04 or 24.04 running under WSL2
#   - ROCm 7.2.1 installed inside the WSL2 Ubuntu environment
#   - Python 3.12 inside WSL2
#
# See docs/ENVIRONMENT_SETUP.md for the full install sequence. Once ROCm is
# installed inside WSL2, install PyTorch with:
#
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/rocm7.0
#
# (check https://pytorch.org/get-started/locally/ for the exact index URL
# matching the ROCm version actually installed, since these change).
